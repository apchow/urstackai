The core loop

Detect → decide → rewrite → log, in the browser

01 · DETECT

Typed spans, not vibes

Exact rules (AWS, GitHub PAT, JWT, PEM, Stripe), checksum validators (PAN/Luhn, Aadhaar/Verhoeff, IBAN), then a Shannon-entropy sweep for unknown secrets. Every finding carries a category, severity and confidence.

02 · DECIDE

Policy-as-code

A versioned JSON policy maps each category to allow, warn, redact or block — with per-domain overrides and allowlists. Reviewable in a pull request, diffable, exportable.

03 · REWRITE

Keep the user moving

Sensitive spans become typed placeholders like <EMAIL_1> so the prompt still works. The token map is session-only, held per tab, and never serialized.

04 · LOG

Evidence, not content

The audit record stores event id, tool, categories, action, policy version and a prompt hash. The hash proves a paste was handled without keeping the secret.

Default policy

CategoryActionWhy

email / phoneRedactPaste proceeds, identifiers replaced

allowlisted sender or repoAllowFalse positives kill adoption faster than leaks

Two invariants, tested in CI

INV-1 — raw prompt text never reaches storage or network A runtime assertion throws if a stored record contains any key matching /prompt|content|text|raw/i. JSONL export is metadata-only.
INV-2 — token maps are cleared on tab close and navigation The placeholder map lives in a per-tab structure, never in storage, never in a message payload. After the tab closes the original is unrecoverable.
